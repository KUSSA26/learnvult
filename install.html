Install LearnVult

LearnVult is installed straight from this website, not from the Play Store. It is free. You need an Android phone with Android 7.0 or newer and about 150 MB of free space.

Install · Update · Share without internet · Problems

1. Install

  1. On your phone, open the download page:
    Download LearnVult
  2. Under Assets, tap the file that ends in arm64-v8a.apk. This is right for most phones made since 2017.
    If your phone is older or very low-cost and that file will not install, use the one ending in armeabi-v7a.apk instead.
  3. When the download finishes, tap Open (or find it in Files → Downloads).
  4. If the phone says it cannot install apps from this source, tap Settings, turn on Allow from this source, then go back and tap Install.
  5. If Google Play Protect warns you about the app, tap More details and then Install anyway. The warning appears because LearnVult is not in the Play Store.
  6. Open LearnVult and sign in, or create an account and choose your school.
Stay safe: only install LearnVult from github.com/KUSSA26/learnvult or from a classmate's or teacher's phone that has the app. Never install a copy someone sends you from another website.

2. Update

LearnVult tells you when a new version is ready:

  • "Version … is available": tap Download update, open the file and tap Install. It installs over your current app. Your downloads, folders and settings are kept, and you stay signed in.
  • "Please update LearnVult": your version is too old to connect any more. Update the same way. Until you do, you can still open the materials you have downloaded, but you cannot sync.

You can also check yourself: Settings → App updates → Check for updates.

3. Share the app without internet

Once one person has LearnVult, others can get it from their phone, with no data needed.

  1. Both phones: turn on Bluetooth and Location.
  2. On the phone that has LearnVult, open Files by Google, tap Share (or Nearby Share), choose Send, select Apps, tick LearnVult and send it. On newer phones you can also use Quick Share.
  3. On the other phone, accept the transfer, then tap the LearnVult file to install it. Follow steps 4 to 6 of Install.

To share learning materials (not the app), use Nearby sharing inside LearnVult.

4. Problems

  • "App not installed": try the other file (armeabi-v7a instead of arm64-v8a), free up some storage, and make sure the version you are installing is not older than the one you have.
  • "There was a problem parsing the package": the download did not finish. Delete the file and download it again on a better connection.
  • "App not installed as package conflicts": the LearnVult on the phone came from somewhere else. Uninstall it, then install from the link above. You will need to sign in again and download your materials again.
  • No sign-up email: check your spam folder, wait a few minutes, then ask for it again.
For school IT staff: each release lists SHA-256 checksums in SHA256SUMS.txt so you can check files copied between computers. All releases are signed with the same LearnVult key.
